# Morbol Cosplay Model / UV Viewer

[모델과 UV 대조 화면](https://nam5an.github.io/2/?v=28)

- 상단 탭에서 마감 포함 / 외피만 버전을 선택합니다.
- 두 버전 모두 외피 틈을 연결한 수정 모델입니다.
- 파츠 표시, 회전·확대·이동, 번호표·메시선·색상 설정은 버전마다 유지합니다.
- 각 화면의 Blender 다운로드로 해당 수정 모델을 받습니다.
- 추가 연결면의 UV는 기존 UV 아래에서 확인합니다.

자세한 내용은 [외피 연결 수정](외피-연결-수정.md)을 참고하세요. UV에는 실물 재단을 위한 시접·원단 특성이 반영되지 않았습니다.
