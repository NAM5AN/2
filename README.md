# 몰볼 대조 화면 v47

큰 촉수 접합 경계의 뾰족한 끝부분을 둥글게 다듬었습니다. 서로 맞닿는 외피의 경계를 함께 조정하고, 중앙 촉수 뒤쪽에 겹친 작은 돌출면도 정리했습니다. 몸통과 촉수 뿌리의 볼륨은 유지합니다.

J01 뒤면과 T05·T06, T21·T22 사이의 접합부를 국소적으로 정리했습니다. 서로 맞닿는 양쪽 외곽을 함께 조정하며, 큰 촉수의 전체 실루엣과 뿌리 볼륨을 보호합니다.

기존 정리도 유지합니다. 촉수와 가시 46개의 별도 끝마감 C는 다시 만들지 않았습니다. 외피 전용 H10 뿌리 패치의 통합, 자잘한 보정면의 정리, H20 도안의 연결과 J01-B·T21-A·T22-A의 바닥 외피 통합도 유지합니다.

버전 1은 내부 마감 B01·L01을 포함하고 버전 2는 외피만 표시합니다. 왼쪽 모델과 오른쪽 UV는 각각 선택할 수 있습니다. 현재 UV·SVG 저장과 Blender 파일은 같은 형상을 사용하며, 이전 참고 이미지는 수정 전 자료입니다.

현재 도안은 형태와 연결 경계를 대조하기 위한 자료입니다. 시접·착용자 실측·원단 두께와 늘어남은 아직 반영되지 않았습니다. 실물 크기의 완성 재단 도안으로 검증한 자료가 아닙니다.
