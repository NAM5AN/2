# 몰볼 대조 화면 v46

촉수와 가시의 별도 끝마감 조각을 없애고, 외피 끝에서 봉합하도록 정리했습니다. H20 도안의 끊긴 부분도 연결했습니다. 외피 전용 버전에서는 H10 뿌리 패치와 자잘한 보정면도 이웃 외피에 합쳤습니다.

중간·짧은 촉수와 머리 가시 46개는 작은 원형 끝마감을 별도 조각으로 남기지 않고 외피 A의 끝에서 닫습니다. 외피 전용 버전의 H10 뿌리 패치와 자잘한 보정면 8곳은 인접 외피에 연결했습니다. 이 8곳은 폭 1mm 미만의 경계 보정으로, 큰 원단 조각 8개를 줄였다는 의미는 아닙니다. 내부 마감을 포함한 버전의 큰 접촉면은 역할에 맞게 유지합니다.

현재 파츠 UV와 SVG 저장에는 최신 모델에서 실제로 연결된 조각만 표시합니다. 이전 참고 이미지에는 수정 전 끝마감이나 보강 조각이 남아 있을 수 있습니다. 메시의 삼각형 한 면이나 색상 구역 하나를 별도 천 조각으로 세지 않습니다.

기존 하부 외피는 J01-B, T21-A, T22-A에 합친 상태를 유지합니다. 바닥의 막힌 표면, 촉수 뿌리의 볼륨과 몸통의 둥근 외형을 보호합니다.

버전 1은 내부 마감 B01·L01을 포함하고 버전 2는 외피만 표시합니다. 기존 머리 작은 옆가시 5개는 제거된 상태를 유지합니다. 왼쪽 모델 표시와 오른쪽 UV 선택은 독립적입니다.

현재 UV와 Blender 파일은 같은 형상을 사용합니다. 같은 연결 번호끼리 맞춰 재봉하며, 삼각형 메시 선은 재단선이 아닙니다. 시접·착용자 치수·원단 늘어남은 아직 반영되지 않았습니다. 이전 참고 도안과 현재 제작 대조용 UV를 구분해 확인하세요.
