# Morbol Cosplay Model / UV Viewer

몰볼 코스튬 모델과 UV 대조 화면입니다.

- [모델 버전 선택](https://nam5an.github.io/2/?v=27)
- [버전 2 · 외피만 보기](https://nam5an.github.io/2/?v=27&version=2)
- 버전 1: 기존 v24 모델과 마감면을 포함한 대조 화면을 보존했습니다.
- 버전 2: 외형을 유지하며 내부 마감·접촉면을 제외한 별도 모델과 UV입니다.
- 두 버전의 표시 설정을 각각 유지하며 상단 탭으로 전환합니다.
- UV에는 실물 재단을 위한 시접·원단 특성이 반영되지 않았습니다.

자세한 차이는 [외피 버전 설명](외피-버전-설명.md)을 참고하세요.
