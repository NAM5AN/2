# 몰볼 대조 화면 v40

몸통의 둥근 곡면을 기준으로 큰 촉수의 뿌리와 접합부를 정리했습니다. T05·T06은 각각 한 개의 연결된 촉수이며, 대조 색은 실제로 함께 재봉하는 외피 조각을 구분합니다.

v40에서는 촉수 양옆 접합부와 안쪽 주름에 남은 빽빽한 메시를 정리했습니다. 앞·뒤 상단의 기존 정리 결과와 뿌리 볼륨, 둥근 몸통, 기존 재봉 조각 구성은 유지합니다.

T05·T06 외피는 각 A 한 장에 뒤쪽 봉합선과 짧은 다트 하나를 둡니다. J01·T03·T04는 넓은 A/B 두 조각, T21·T22는 A 한 장입니다. L01은 큰 촉수 전체가 함께 쓰는 상단 마감 A 한 장입니다.

버전 1은 내부 마감면을 포함하고, 버전 2는 외피를 보여 줍니다. 파츠별 표시와 번호표·메시 선·사람 표시를 각각 선택할 수 있습니다. 왼쪽 모델과 오른쪽 UV는 따로 선택할 수 있습니다.

두 버전의 Blender 파일과 현재 UV는 같은 형상을 사용합니다. 메시의 삼각형 선은 재단선이 아닙니다. 조각의 바깥선과 같은 연결 번호를 맞춰 확인하세요.

현재 UV는 시접을 넣기 전의 모델 대조용입니다. 실제 제작에는 착용자 치수, 원단 두께와 늘어남, 시접을 반영한 시험 맞춤이 필요합니다. 이전 도안(v31) 페이지와 PDF는 이전 형상의 참고 자료로 보존했습니다.
